## 1. 会话与对话

### 1.1 新建会话

**入口**：侧边栏「快速对话」，或工作空间标题 hover 出的 `+`，或工作空间内右键。

**操作**：
1. 在 composer 顶部信息栏确认**工作空间**（必须）、**工作位置**（主工作区 / 新工作树）、**分支**。
2. 选择处理模式（Direct / 工作流 / AUTO），按模式设置配置。
3. 输入需求，可选添加附件 / 文件引用 / 引用片段。
4. 点发送。

**注意**：
- 草稿（正文 + 附件 + 右侧工作区 Tab）在跨页面导航时**保留**；只有发送成功或切换目标工作空间才清空。
- 发送前会校验 workspace 存在、模式配置完整、工作流模板合法、附件合规；失败会内联在 composer 下方，不自动消失。

### 1.2 补充输入与排队

- 运行中可以直接在 composer 继续输入并发送，进入「待发送」队列。
- 队列项可编辑、删除；界面显示 `已用/上限`。
- 队列在页面上方有独立的条目区，可以展开/收起。

### 1.3 引用（Quote）

**入口**：选中任意消息正文、代码块、diff 片段 → 浮出「引用」按钮。

- 引用的内容以 chip 形式挂在 composer 上下文区；
- 有单条消息字符上限与条数上限，超限会明确报错并告诉你剩余额度；
- 引用会随消息一起发给 Agent，消息气泡里可展开查看引用详情。

### 1.4 文件引用（区别于附件）

**入口**：工作空间文件树 / 搜索结果 → 右键 →「引用到对话」。

- 只传"引用"（`projectId + 相对路径`），不读正文、不复制文件；
- 重复引用自动去重；
- 发送后用户消息里显示为文件 chip，点击可打开对应文件。

### 1.5 附件

| 维度 | 规则 |
| --- | --- |
| 入口 | 纸夹按钮、拖拽进 composer、粘贴图片 / 文件 |
| 数量 | 最多 10 个 |
| 单文件 | ≤ 25 MB |
| 总计 | ≤ 100 MB |
| 超长粘贴 | 粘贴文本 > 6400 字符时自动转为文本附件 |
| 预览 | 图片显示缩略图（右键可「复制图片」「图片另存为」）；文本 / Markdown 在右侧 Tab 打开 |
| 生命周期 | 初始附件绑定 task，重跑复用；追问附件走 ACP 输入内容 |

### 1.6 会话操作（侧边栏会话行）

| 操作 | 触发方式 | 说明 |
| --- | --- | --- |
| 重命名 | hover 行尾图标 | 标题属于 Task 领域，是唯一事实源 |
| 置顶 / 取消置顶 | hover 行尾图标 | 置顶区可手动拖拽排序 |
| 删除 | hover 行尾图标 | 有运行中的 run 会被拒绝；删除走确认对话框 |
| 常驻 / 解除常驻 | 右键菜单（仅 Direct） | 防止空闲回收 |
| 展开 run 历史 | 点击 Workflow/AUTO 会话 | 同一时间只展开一个会话的 run 列表 |

**排序规则**：同一工作空间内按最近活动时间倒序。只有四类 durable 边界会推进活动时间：创建成功、Prompt 被接受、回合终态写入、后台新回复写入未读。

### 1.7 会话内查看面板

会话标题栏右侧：

| 面板 | 内容 |
| --- | --- |
| **系统提示** | 本次会话实际注入的 system prompt（可渲染 Markdown 或看源码） |
| **原始帧** | ACP JSON-RPC 收发帧，支持关键词搜索、按事件类型 / 方向过滤、排序、分页 |
| **产物** | 当前节点的规范化产物 |
| **附件** | Agent 或节点产生的附件 |

> 排查"Agent 为什么不听话"时，先看系统提示，再看原始帧。

## 2. 工作流编辑

**入口**：`运行模式` → `工作流模式`；或会话页顶部「工作流」卡片 → 新建 / 修改 / 修复。

### 2.1 画布操作

| 操作 | 方式 |
| --- | --- |
| 添加节点 | 画布左上 `+` 菜单（Agent / AI-DYNAMIC / 结束节点 / New Round） |
| 添加边 | 从节点右侧把手拖到目标节点（也可点起点再点终点） |
| 删除 | 选中后 `Delete` / `Backspace`，或用画布左上统一删除按钮 |
| 撤销 / 重做 | `Ctrl/Cmd+Z` / `Ctrl/Cmd+Y` 或 `Ctrl/Cmd+Shift+Z` |
| 平移 / 缩放 | 拖动画布 / 滚轮；fit view 控件 |
| 查询问题 | Inspector 顶部问题摘要，点击定位 |

### 2.2 Inspector（右侧配置）

**选中节点时**，三块按固定顺序：

1. **模型配置**：Agent、模型、思考强度等 config options、权限模式（含 Auto Accept）、「同步至其他节点」。
2. **工作流控制**：`max_attempts`、`max_rounds`（留空 = 不限制）。
3. **节点配置**：node id、goal、profile、输出协议（output）、结果判定（success_condition / manual_check）。

**选中边时**：`on`（success / failure）、`session`（new / continue）、目标节点（含 `$end` / `$new-round`）。

**未选中时**：直接显示工作流控制卡片。

### 2.3 常见编辑任务

| 想做的事 | 怎么配 |
| --- | --- |
| 测试不通过就回去改 | `test → dev` 配 `on=failure`，并设 `session=continue` 复用会话 |
| 失败最多重试 3 次 | 工作流控制 `max_attempts = 3` |
| 人工验收 | accept 节点勾 `manual_check` |
| 用 JSON 结果自动判定 | test 节点配 `output.kind=json` + `schema` + `success_condition` |
| 验收失败开新一轮 | `accept → $new-round`，`on=failure` |
| 拆出去让 AI 动态编排 | 插入 `ai-dynamic` 节点，配置 allowed workflows 与动态限制 |

### 2.4 注意事项

- 工作流 `id` 在模板库内必须唯一，重复会在保存前聚合提示，后端保存时再校验。
- 所有节点必须从 `entry` 可达。
- 同一节点同一种结果只能有一条出边。
- 工作流一旦启动就冻结快照，改模板不影响正在跑的 run。

## 3. Agent 管理

**入口**：侧边栏「Agent」。

### 3.1 新增 Agent

1. 点「新增 Agent」→ 搜索选择目录中的 Agent（或「自定义 Agent」）。
2. 填显示名称、图标（默认用该 Agent 图标，可换本地图片）。
3. 内置 Agent 的命令 / 参数为只读（由客户端 Catalog 维护）；自定义 Agent 需填 Agent ID 与启动配置。
4. 保存后点**诊断**。

### 3.2 诊断能看到什么

- 能否启动、ACP 初始化是否成功；
- 支持的能力（是否支持 continue session、MCP stdio / HTTP 等）；
- 可用的模型目录；
- 失败时的结构化原因与最近检测时间。

**stale-while-refresh**：诊断期间继续展示上一次结果，完成后一次性替换；只有从未拿到过能力快照的 Agent 才显示 loading。

### 3.3 模型配置

- 点「获取模型配置」可主动抓取当前模型的 config options（思考强度、context、Fast 等）。
- 已观测的模型配置会持久化在 `desktop/agent-model-catalogs.json`，**Doctor 失败不会清空**。
- 模型目录过期时（Agent 已不再提供该模型），系统会把它规范化为「不指定」，不会拿一个不存在的模型去调用。

### 3.4 删除 Agent 前

删除会展示受影响范围：工作流模板、任务工作流、定时任务的数量统计。若部分数据损坏无法确认引用，会明确警告可能失效的引用。

### 3.5 npx 缓存修复

内置 Agent 通过 npx 分发。若诊断提示缓存问题，可点「修复缓存」：清理本次错误涉及的 npx 缓存目录后自动重新检测。**注意**：其他使用同一缓存的工具可能受影响，正在用该缓存的 Agent 可能中断。

## 4. 上下文管理：角色 / MCP / SKILL

**入口**：侧边栏「上下文」，顶部三个一级 Tab。

### 4.1 角色（Profile）

- 角色 = 可复用的执行身份 / 指令集，工作流节点用稳定 `profile id` 引用。
- 内置角色只读，只能"另存为新角色"；自定义角色可增删改。
- 支持搜索（名称 / ID / 摘要 / 正文）。
- **动态模板**开启后，runtime 使用前会按当前执行上下文渲染一次正文（例如注入路径、任务信息）。
- **批量导入**：选文件夹，扫描 Markdown 并批量创建角色。兼容 `name/title` 与 `summary/description`；单文件失败不会中断整批，会在结果里逐条列出错误码。
- 删除前会提示引用情况（模板数、任务数、可继续快照数），确认后才会删除。

### 4.2 MCP

| 概念 | 说明 |
| --- | --- |
| 配置方式 | Local / Remote 两类 Tab，JSON 编辑器（允许 `///` 注释） |
| 顶层 key | 即 server id |
| transport | stdio、HTTP（支持 OAuth） |
| 状态灯 | 🟢 健康 / 🟡 需要授权 / 🔴 不可用 / ⚪ 未检查 |
| 启用开关 | 独立于健康状态，随时可切；开启自动触发检查，关闭清状态 |
| 检查时机 | 保存、重新启用、手动「MCP 服务诊断」；进入 Tab 不批量检查 |
| 会话传递 | 只按 `enabled` 传给 Agent；最近诊断结果**不参与**过滤 |

- **内置 MCP**（渠道注入）只允许查看、诊断、查看工具列表和启停，不能编辑或删除。
- 保存策略是「先保存 → 再验证」：保存 Sheet 保持打开，显示"正在连接…"，成功关闭、失败显示具体错误。

### 4.3 SKILL

- 存储：`~/.gold-band/skills/`（全局）、`<workspace>/.gold-band/skills/`（项目级）、Agent 原生 skills 目录。
- 文件格式：`<name>/SKILL.md`，front matter 含 `name`、`description`、`disable-model-invocation`；正文自由 Markdown。
- 限制：文件 ≤ 100KB，描述 ≤ 1024 字节。
- 创建时显式选择 Global / Project；有工作空间时默认 Project。
- 编辑时 Scope 锁定；改名会移动真实目录并重建同步链接。
- 同名冲突实时检测，冲突时禁用保存。
- 运行时按 `Project > Global > BuiltIn` 优先级去重，catalog 预算 50KB，只加载当前 workspace 的项目 SKILL。
- 卡片左下角图标展示"来源 Agent + 已同步目标 Agent"的并集；可在页面上按"当前 Agent 可用"筛选。

## 5. 运行模式管理

**入口**：侧边栏「运行模式」。

| 项 | 说明 |
| --- | --- |
| 页面范围 | 只管理 **工作流模式** 与 **AUTO 模式**（Direct 配置在 composer 内闭环，不在这里） |
| 项目切换 | 顶部项目选择器；配置属于项目级记忆，切项目加载该项目自己的配置 |
| 保存方式 | **没有页面级保存按钮**：切 tab、切模板即生效 |
| 保留规则 | 切到工作流不会清空 AUTO 配置，反之亦然 |

### AUTO tab 可配置项

- Agent 策略：固定 Agent / 动态 Agent；
- 固定策略：Agent、模型、权限、Auto Accept；
- 动态策略：初始分发 Agent、分发模型、验收模型、控制面权限、各 worker Agent 的模型 / 权限 / 思考强度、Agent 决策指南；
- 允许调用的工作流（`workflow.id`）、可用角色列表；
- 动态控制限制。

### 工作流 tab

- 模板列表 + 画布编辑器；
- 校验失败会列在「异常工作流」区域；
- 支持「另存模板」「删除模板」。

## 6. 右侧工作区：文件

**入口**：右侧工作区「新建 Tab」→「工作空间」（或空态直接点入口）。

### 6.1 浏览与搜索

- 目录**按层懒加载**，虚拟化渲染；支持「紧凑目录 / 树形目录」两种模式。
- 紧凑目录会把"只有一个子目录且没有文件"的连续链合并为一行（`a/b/c`），需要操作中间目录时切树形。
- 搜索在后台执行，遵守 `.gitignore`，包含 `.github` 等隐藏项但跳过 `.git`；支持模糊匹配（`wft` 可命中 `WorkspaceFileTree.tsx`）。
- 搜索结果的排序：文件名完全匹配 > 文件名前缀 > 文件名模糊 > 仅路径模糊。

### 6.2 编辑与管理

| 操作 | 方式 |
| --- | --- |
| 新建文件 / 文件夹 | 目录或空白处右键 → 新建；行内输入，Enter 提交、Esc 取消 |
| 重命名 | 右键 → 重命名（默认只选中主名） |
| 删除 | 右键 → 删除，**移入系统回收站** |
| 撤销上一步 | 目录树聚焦时 `Ctrl/Cmd+Z`（新建 → 移入回收站；重命名 → 改回；删除 → 还原）；每项目最多 20 步 |
| 复制路径 | 右键 → 复制绝对路径 / 复制相对路径 |
| 在文件管理器中打开 | 右键 |

- 同一时间只允许一个条目写操作，其他操作会被忽略。
- 有未保存编辑时删除 / 重命名会额外警示；冲刷失败则拒绝该操作。
- Windows 绝对路径会自动去掉 `\\?\` 前缀，UNC 路径恢复为标准 `\\server\share`。

### 6.3 查看格式

| 类型 | 能力 |
| --- | --- |
| 文本 / 日志 | CodeMirror：行号、查找、折行、编辑 |
| Markdown | 默认实时预览，可切源码；本轮新增附件可编辑，历史 / 运行目录文件只读 |
| 代码 / 配置 | 按需语言高亮，无语言包时回退纯文本 |
| 图片（PNG/JPEG/WebP/GIF/BMP/ICO） | 安全预览、缩放、适应窗口、原始大小、拖拽平移；GIF 可播放 / 暂停 |
| SVG | `<img>` 矢量预览，可切源码；工具栏「在浏览器中打开」可用脚本 |
| HTML | 默认打开源码，内容区右上浮层按钮可打开内置浏览器 |

### 6.4 会话文件链接

- 会话里的本地文件链接是"文件图标 + 语义链接文字"，不是普通 URL。
- 带 `:line:column` 或 `#Lline-LendLine` 时，名称显示为 `文件名:位置`，点击直接定位并居中滚动。
- 工作空间外的文件只能通过你**显式点击**会话链接打开；打开后详情显示不可点击的绝对路径。

### 6.5 工作位置相关

- 文件根跟随当前会话的工作位置：主工作区 / linked worktree / 不可用（已收回）。
- worktree 已收回时，Tab 显示「会话工作树已收回」+ 原路径 +「浏览主工作区」按钮；**不会自动回落**项目根。
- 「运行目录」是另一类只读资源，展示当前 attempt 的产物，默认不可编辑。

## 7. 右侧工作区：源码管理

**入口**：右侧「新建 Tab」→「源码管理」。

### 7.1 能做什么

| 分组 | 能力 |
| --- | --- |
| 更改 | 已暂存 / 未暂存 / 未跟踪 / 冲突；Stage、Unstage、全部暂存；放弃更改（还原到 HEAD，不可撤销） |
| 提交 | 提交主题 + 可选正文；已暂存文件计数 |
| 历史 | 提交列表分页（每页前端 300 条）、提交详情、多选聚合审阅（最多 32 个提交）、Diff |
| 仓库 | 分支、标签、Worktree、Fetch / Pull / Push / Push Tag、Stash |
| GitHub | 能力检测、PR / Issue 列表与详情、PR 文件 Diff（缓存最多 96 项） |

### 7.2 工作位置绑定

- 会话页的「源码管理」跟随当前选中会话的工作位置：
  - `main` → 项目根；
  - run worktree / dynamic 子工作树 → 各自路径；
  - `unavailable` → 提示已收回，需要你主动点「浏览主工作区」。
- 同一工作位置内切换节点不会重载 Git 数据（identity 不变）；跨工作位置才切换仓库会话。

### 7.3 并发与状态

- 同一工作空间**任意时刻只允许一个 Git 写操作**；进行中的操作在按钮上转圈，其他写操作禁用。
- 后台只读刷新用独立状态，不禁用提交草稿。
- 长操作（fetch/pull/push/stash、GitHub 登录、PR 创建）通过事件推送状态，不轮询。
- 切换分支 / 创建并检出新分支、Fetch / Push 的 remote 选择都会持久化（remote 偏好按仓库共享，linked worktree 共用）。

### 7.4 常见前置问题

| 提示 | 处理 |
| --- | --- |
| 尚未安装 Git | 安装系统 Git 后点「重新检测」 |
| 当前文件夹不是 Git 仓库 | 可点「初始化仓库」（只建库，不自动暂存 / 提交） |
| Git 版本过低 / 无法识别 | 升级后重新检测 |
| Git 仓库还没有首次提交 | 先暂存文件并创建首次提交 |
| 当前 Git 不支持 Worktree | 升级系统 Git |

## 8. 右侧工作区：内置浏览器

**入口**：右侧「新建 Tab」→「浏览器」；或点会话 / Markdown 里的 `http(s)` 与本地 `.html` 链接。

### 8.1 能力

- 多页签（一个工作区 Tab 内多页）、前进 / 后退 / 刷新 / 地址栏；
- 加载中刷新按钮变「停止」；无完成事件时 15 秒解除遮罩；
- 地址栏区分网址与搜索词，搜索引擎可选百度 / Google / Bing；
- 电脑版 / 移动版切换（默认电脑版）；
- 普通左键链接当前页跳转；`Ctrl+点击`、右键「新窗口」、`window.open` 拦截为内部新页；
- 进程内一份 Cookie profile，登录态跨重启保留；
- 下载走系统「另存为」，无应用内下载面板；
- 书签图标可加入 / 移除当前站点。

### 8.2 不做的事

- 不从本机 Chrome / Edge / Firefox 导入 Cookie；
- 无下载队列 / 进度 / 历史；
- 无扩展、多 profile、书签栏、默认开发者工具；
- 重启不恢复打开的 URL 列表；
- `mailto:` / `tel:` 仍走系统应用。

### 8.3 本地 HTML

- 工作空间 / 运行目录树里的 `.html` 默认打开**源码**，内容区右上浮层按钮才打开内置浏览器；
- 会话与 Markdown 中的本地 HTML 引用直接进内置浏览器；
- 本地 HTML 引用上级目录资源（如 `../node_modules/x.js`）时，若越出授权目录会提示，由你确认放开。

## 9. 定时任务

**入口**：侧边栏「更多」→「定时任务」；或 composer 发送按钮右侧 `⌄` →「创建定时任务」。

### 9.1 创建

1. composer 点 `⌄` →「切换为创建定时任务」；主按钮变成 `⏰ 创建定时任务`，右侧出现齿轮。
2. 点齿轮，在右侧工作区打开「定时任务设置」Tab 配置计划与运行策略。
3. 计划类型三段式：**单次 / 重复 / Cron**；重复内可选每小时、每天、工作日、每周（多选星期）、每隔（分钟 / 小时）。
4. 点主按钮保存。创建后提示"定时任务已创建，查看定时任务"，5 秒后自动消失。

### 9.2 创建时的规则

- 正文就是指令（instruction）；附件会被复制到定时任务输入目录。
- 已添加的引用（Agent 消息、文件、diff）会冻结进内容快照，每次触发都携带同一组。
- 沿用当前 Agent / 模型 / 权限配置，不做"无人值守"能力映射。
- 校验继承当前模式的规则（Agent、Workflow、附件）。
- **Workspace 固定用主工作区**，不提供「新工作树」。
- 创建不会立即执行；首次到达计划时间才物化 Task 并执行。

### 9.3 会话策略

| 策略 | 适用 | 行为 |
| --- | --- | --- |
| `new` | 全部模式 | 每次触发都是新 task / run / session |
| `continuous` | 仅 Direct | 首次触发建 task/run/session；后续触发向同一 ACP session 发新 prompt，不建新 run |

### 9.4 管理

- 列表：任务、计划、下次执行、最近运行、启用开关；支持工作区筛选、状态筛选。
- 操作：查看详情、立即执行、编辑、停用 / 启用、删除。
- **立即执行**会马上创建一次手动触发记录，**不改变**计划的下一次执行时间。
- 详情页有执行历史（每页分页）、上轮状态、执行次数、重试次数、下次执行、时区。
- 状态：待执行 / 执行中 / 重试中 / 成功 / 失败 / 已跳过 / 已错过 / 需要处理。

### 9.5 全局运行设置（设置页）

| 设置 | 说明 |
| --- | --- |
| 保持系统唤醒 | 允许屏幕休眠，只阻止空闲导致的系统睡眠；只在"用户开启 + 至少一个启用任务 + 应用在运行"时生效 |
| 完成通知 | 任务成功完成时发系统通知 |
| 历史保留天数 | 1–3650，默认 30；只清理诊断记录，accepted 执行历史与活动 Run 不删 |

## 10. IM 远程干预

**入口**：设置 →「通用」→「IM 远程干预与通知」。

### 10.1 接入步骤（企业微信）

1. 点「扫码接入」。
2. 手机企业微信扫码并确认授权。
3. 在目标会话中**主动给机器人发一条私聊消息**，完成绑定。
4. 状态从「等待绑定」变成「可用」后才算接通。

> 微信通道当前**未提供**（等待稳定主动推送的真实验证）。

### 10.2 接入步骤（飞书）

1. 点扫码接入 → 确认三项权限（发送消息、读取发给机器人的私聊消息、更新机器人卡片）。
2. 在飞书原生页面选择已有应用或新建应用。
3. 扫码账号给机器人发一条私聊消息完成绑定。

### 10.3 能做什么

- 权限请求：在 IM 里点同意 / 拒绝；
- 用户追问：在 IM 里选择 / 填写答案；
- 人工 check：在 IM 里点「成功」/「失败」；
- 信息类通知：按类别订阅 Run 与 ACP 回合的结果通知。

任一端处理成功后，桌面端与另一端同步收敛到同一终态；只有"先到"的那次写处理结果，重复点击不会重复执行。

### 10.4 边界

- 每个渠道只绑定**一个机器人、一个授权用户、一个一对一私聊**；一个机器人只连一台设备。
- 不支持群聊、自然语言指令、通过 IM 启停 / 重跑 / 编辑工作流。
- 不提供云端中转；客户端退出、电脑休眠、断网期间不保证实时收发。
- 卡片能力差异（如企业微信多题单选最多 3 题，4 题以上整体跳过）由平台限制决定。

## 11. 需求管理（Multica）

**入口**：侧边栏「更多」→「需求管理」。

1. 「连接」填写服务端地址并建立连接。
2. 「添加工作空间」把远程工作空间绑定到本地项目。
3. 在需求列表里查看待办 / 进行中 / 已完成 / 失败。
4. 点「执行」领取并在本地跑；点「取消任务」取消。
5. 「移出列表」只从码灵侧列表移除（刷新会恢复）；终态任务可「移出并删除本地完成记录」。

## 12. 设置与个性化

**入口**：侧边栏底部「设置」。顶部三个 Tab：通用 / 个性化 / 高级。

### 12.1 个性化

| 分组 | 能力 |
| --- | --- |
| 设计风格 | Gold Band 主题（默认）/ 技术中性；点「选择主题」在右侧抽屉切换 |
| 明暗模式 | 跟随系统 / 浅色 / 深色（`跟随系统` 只切当前主题的明暗，不换主题包） |
| 视觉效果 | 完整效果 / 性能优先（仅支持该能力的主题可见） |
| 字体 | 界面 UI 与编辑器分开；默认字体栈或自定义有序栈（最多 16 项）；UI 字号 12–18px，编辑器 10–18px |
| 壁纸 | 浅色 / 深色分别配置；PNG/JPEG/WebP，源 ≤ 32 MiB、≤ 4096px、≤ 1600 万像素；可见度 20%–100% |
| 头像 | Agent 与个人头像，支持上传裁剪与最近使用 |

### 12.2 通用

- 语言（七种，母语自称排序）。
- 定时任务运行设置（见 9.5）。
- IM 远程干预与通知（见 10）。

### 12.3 高级

- 更新地址覆盖、后台检查、手动检查更新。
- 日志：是否记录详细日志（DEBUG）。
- **受信任的图片域名**：Markdown 网络图片默认不加载，需你在图片占位上点「加载」后把该 host 加入信任列表。列表可移除，不提供手动添加。
