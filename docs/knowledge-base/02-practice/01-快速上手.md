# 快速上手

> 目标：从零到跑通第一个会话，大约 10 分钟。

## 1. 安装

1. 从 Releases 下载对应平台安装包（Windows / macOS / Linux），或从源码构建。
2. Windows 安装包按系统界面语言选择语言，未匹配时用英文。
3. **macOS 特别注意**：当前 Release 没有 Apple Developer Program 证书，未做 Developer ID 签名与公证，首次打开会被 Gatekeeper 拦截。请按 [macOS 安装与排障指南](../../guide/macos-install.zh-CN.md) 操作。

## 3. 五步跑通第一个会话

### 第 1 步：添加工作空间

- 侧边栏底部「添加工作空间」→ 选择本地项目目录。
- 工作空间身份由**规范化路径**决定，路径大小写不同视为同一个项目。
- 项目目录里只会写一份可覆盖配置 `.gold-band/`；所有过程数据都在用户目录，不污染仓库。

> 也可以在工作空间标题行 hover 时点 `+` 直接在该空间新建会话。

### 第 2 步：配置并诊断 Agent

- 侧边栏「Agent」→「新增 Agent」→ 从目录选择（比如 Claude 或 Codex）→ 填写必要配置。
- 点卡片上的**诊断**，确认状态正常；有模型配置需求时点「获取模型配置」。
- 前提：本地已经能启动该 Agent（例如 Claude Code / Codex 已在机器上可用并登录）。

> 内置 Agent 的启动命令由客户端维护，不需要你手写；只有「自定义 Agent」才需要自己填命令与参数。

### 第 3 步：选运行模式

composer 上方的分段：**Direct / 工作流 / AUTO**。

- **第一次用，选 Direct。** 它最接近"直接用 Agent"，所有配置都在当前输入框里闭环：选 Agent、选模型、选权限。
- 需要固定流程时选工作流；需求大到画不出流程时选 AUTO。

### 第 4 步：输入需求并发送

- 直接输入需求文本（首行会被截断成会话标题，默认取前 48 个字符，可在 `configs/app-config.toml` 的 `conversationAutoTitleMaxChars` 调整）。
- 可附加文件：纸夹按钮选择、拖拽、粘贴图片；最多 10 个文件，单文件 ≤ 25 MB，总计 ≤ 100 MB。
- 粘贴超长文本（>6400 字符）会自动转成一个文本附件，不影响输入框已有内容。
- 点发送，进入会话运行页。

### 第 5 步：看结果、审阅、提交

- 中间是会话流：Agent 回复、思考、工具调用、权限请求、附件、文件变更摘要。
- 右侧工作区可用：
  - **工作空间**：浏览 / 编辑文件；
  - **源码管理**：看 diff、Stage、Commit；
  - **内置浏览器**：预览页面或本地 HTML；
  - **产物 / 附件 / Diff**：按需打开对应资源。
- 会话标题栏的「系统提示」「原始帧」用于排查"Agent 到底被喂了什么"。

## 5. 三条新手最容易踩的坑

1. **没诊断 Agent 就发会话**：模型与权限下拉会是空的或显示"尚未获取此模型的配置"。先回 Agent 管理诊断并获取模型配置。
2. **在 Workflow/AUTO 里期待"随便聊"**：跑工作流时 Agent 的职责是完成当前节点。想自由追问请用 Direct；工作流中途停止后的普通消息不会推进流程，只有「继续工作流」才会。
3. **找不到之前的会话**：会话按工作空间分组。切换工作空间后，之前的会话在新工作空间里看不到——点回原工作空间即可。
