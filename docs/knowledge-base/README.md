## 一页读懂 MALING

> **命名说明**：本产品原名为 **Gold Band**，现更名为 **MALING**。本知识库统一使用 MALING 指代产品；文档中出现的 `~/.gold-band/`、`GOLD_BAND_HOME`、`gold-band run`、内置主题「Gold Band」等属于**实现标识**，保持原命名不变（详见 [架构与扩展点 §10](03-reference/01-架构与扩展点.md#10-发布渠道与产品命名)）。

**一句话定位**：MALING 是一个本地优先的开源 AI Agent 桌面客户端。它通过 ACP（Agent Client Protocol）连接 Claude Code、Codex 等主流 Coding Agent，把「对话、工程工作流、产物审阅」放进同一个桌面工作区。

它解决三个问题：

1. **控制流容易漂移**：流水线步骤一旦写进模型上下文，长任务执行到中途就容易走偏。MALING 把控制流从模型里拿出来，交给 deterministic 的 runtime。
2. **子任务难复用你已有的生态**：每个节点可以是**不同的 Agent**（不同的 harness），而不只是不同的提示词。
3. **「是否完成」不能靠 Agent 自报**：完成判断基于 canonical 产物与验证，而不是模型说「我做完了」。

## 文档之间的关系

- 本知识库是**提炼层**，回答「是什么、怎么用、为什么这样设计」。
- 更细的工程契约在 `docs/gold-band/` 下：产品设计文档、开发计划、工程规则（`docs/gold-band/rules/`）。
- 两者冲突时，以 `docs/gold-band/产品设计文档` 为准，并回头修正本知识库。

## 维护约定

- 新增/修改**对外可感知**的功能（界面、交互、运行模式、能力边界）时，同步更新本知识库对应章节。
- 每个章节末尾都有「延伸阅读」，指向权威设计文档；不要在本知识库里复制大段实现细节。
- 文档里的路径、菜单名、按钮文案与客户端实际界面保持一致，方便边看文档边操作。
