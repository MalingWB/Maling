## 设计与性能复核

冲突修复继续使用 canonical action、session snapshot、revision 与现有连接生命周期，未在上游方案之外新增并行状态机、持久表、缓存、队列或依赖。IM 变化只增加一个结果枚举分支，单次处理规模仍受当前表单上限约束，不增加网络请求和历史读取。会话沿用上游摘要/详情分离与既有渲染隔离机制，子 Agent 待绑定公告受 64 条、单条 16 KiB 上限约束；不把功能冒烟测试声称为性能 benchmark。

浏览器验证使用本地生产构建与隔离 fixture；不等价于真实飞书/企微平台、真实 ACP provider 或打包 EXE 验收。不发送真实渠道消息、不操作用户任务或凭据。

Claude ACP 的上游握手要求实际运行版本至少 0.90.0。目录生成策略已固定到该版本，但本轮没有启动用户的真实 provider，不能以 catalog 更新替代本机 adapter 版本和真实协议验收；需要隔离官方 adapter 与本地 HTTP fixture 的 opt-in 协议探针仍保持忽略。
