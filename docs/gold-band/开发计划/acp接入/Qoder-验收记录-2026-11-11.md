# Qoder CLI 真实验收记录（2026-11-11）

## 结论

Qoder CLI `0.2.14` 在 Windows x64 上的首次真实验收未通过。升级到 `1.1.86` 并领取 Credits 后，固定 npm launcher 与本机 `qodercli` 命令路径已于 2026-11-12 完成完整生命周期与 Skill 验收。2026-11-12 确认本机路径以 PATH 中实际解析到的 `qodercli` 命令为验收标准，Qoder Windows x64 真实验收通过；native 二进制被本机安全环境拦截的事实作为环境记录保留，不构成发布门槛。第一阶段 Catalog 产物已于同日生成，正式精选集合扩展为 13 项。

阻断项不是测试环境缺项，而是固定版本在真实环境下可重复复现的 ACP 契约缺陷：

- `qodercli login` 登录成功，但 ACP 默认 `qodercli-login` 认证在 native 与固定 npx 两条 launcher 上都超过 120 秒不返回，最终只能改用 `QODER_PERSONAL_ACCESS_TOKEN`。
- initialize 声明 `loadSession = true`，但在正常完成首轮真实工具会话后，native 与固定 npx 的 `session/load` 都返回 `Internal error`。
- `sessionCapabilities.list` 被声明，但首轮 prompt 后的 `session/list` 在两条 launcher 上都返回空 `sessions`。
- 未声明 `close`；进程退出不能自然完成，需要外层强制回收进程树。
- 活动工具 stop 场景没有稳定返回 `cancelled`，本轮 native 结果返回 `end_turn`，不能作为通过证据。

## 1.1.86 复验进展

官方 ACP Registry 已将 Qoder 更新为 `1.1.86`，本地已对该版本做隔离复验：

- initialize 成功，新增声明 `close`、`delete`、`fork`、`resume`、`list` 和 `additionalDirectories` 能力。
- ACP 仍只声明 `qodercli-login` 一个 auth method；直接调用 `authenticate` 仍会超时。
- 使用 `security.auth.selectedType=qoder-pat`、`QODER_PERSONAL_ACCESS_TOKEN`，并避免重复调用 authenticate 后，`session/new` 可以建立。
- 但是首个 prompt 返回 `main model "auto" is unavailable`；显式选择 `ultimate`、`performance`、`efficient` 也无法获得可用模型。
- 1.1.86 原生 ZIP 下载和 Authenticode 校验通过，但解包后的 `qodercli.exe` 在本机启动时被 Windows 拒绝访问，无法完成 native 升级安装；fixed npm 包可正常启动。

因此 1.1.86 目前只证明新版能力面扩大，尚未证明真实代理回合可用。native EXE 的 Windows 拒绝访问问题也必须先解决。当前不得把失败记录改写为通过。

### ACP 复验

- initialize 成功，`authMethods` 仍只有 `qodercli-login`。
- 浏览器登录态下 `session/new` 直接成功，未触发 `authenticate`，说明生产端“先建会话、仅在 AuthRequired 时认证”的顺序正确。
- 首个 `session/prompt` 返回 JSON-RPC 错误 `code=500`，消息为 `main model "auto" is unavailable.`。
- 直接执行 `qodercli -p ... -m qmodel_latest` 同样返回 `Model "qmodel_latest" is not available.`，排除单一模型别名问题。
- 由于模型不可用，真实工具回合、stop、`session/list`、`session/load` + history、close/delete 与 Skill 探测均无法进入，不能记为通过或失败。

### 当前阻断与下一步

阻塞项需要账号侧动作，代码侧无法绕过：

1. 在 [Qoder 账号套餐页](https://qoder.com/account/plan) 确认账号是否仍有 Free 试用、Lite 或 Pro 等包含 Credits 的有效套餐；也可在交互式 CLI 内执行 `/usage` 查看 Plan 与 Credits。
