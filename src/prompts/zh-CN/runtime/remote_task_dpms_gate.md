本任务包含 DPMS 系统需求创建环节：按 DPMS 角色定义完成参数确认与需求创建，创建成功后把返回的需求 ID 写入任务记忆（任务范围）的 `storyId` 键，并把本次实际创建所用产品的数字 ID 写入 `dpms.productId` 键——runtime 只回传这两项关联给工作项平台（其余需求信息由工作项平台按该产品与需求 ID 从 DPMS 拉取），`storyName` 等其余信息键按角色定义写入，供核实复用与后续预填使用。溯源信息中的发布计划、负责人、产品等值是推荐值预填，仍按角色定义经用户确认；`dpms.productId` 必须写确认后实际使用的产品，不能照抄推荐值。任务记忆已有 `storyId` 时，先用它核实需求是否已存在并复用，不重复创建。这两项由 runtime 负责回传给工作项平台，不要调用工作项平台接口。
