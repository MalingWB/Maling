This task includes a DPMS system story creation step: confirm parameters and create the story following the DPMS role definition, and after a successful creation write the returned story ID, name, and link into task memory (`storyId`, `storyName`, `dpms.storyUrl`, task scope). If task memory already has a `storyId`, first verify that story exists and reuse it instead of creating again. Provenance values such as release plan, owners, and product are prefilled recommendations that still require user confirmation per the role definition. The runtime reports the created story back to the work-item platform; do not call work-item platform APIs yourself.
