## 새 기능 및 변경 사항

> [!IMPORTANT]
> 이번 업데이트에서는 로컬 설정을 마이그레이션합니다. 0.21.x에서는 마이그레이션된 설정을 읽을 수 없습니다. 이전 버전으로 돌아갈 가능성이 있다면 업데이트 전에 앱 데이터를 백업하세요.

### 1. 워크플로 그래프에서 현재 노드를 다시 시도하거나 실패한 노드부터 다시 실행

대화에서 워크플로 실행 그래프를 열고 해당 노드를 마우스 오른쪽 버튼으로 클릭하세요.

1. **현재 노드 다시 시도**: 현재 노드가 오류로 일시 중지되어 다음 단계로 넘어가지 않은 경우, 같은 Run에서 해당 노드를 다시 실행합니다. 이전 대화와 결과물은 그대로 유지됩니다.
2. **이 노드부터 다시 실행**: 종료된 실패 기록을 선택하면(다시 실행 가능한 이전 기록 포함) 작업에 저장된 최신 워크플로 설정으로 해당 노드부터 새 Run을 시작합니다. 기존 Run은 읽기 전용 기록으로 남습니다.

> [!WARNING]
> 실패한 노드부터 다시 실행하면 기존 Run에서 아직 진행 중인 실행이 중단됩니다. 작업 공간의 변경 사항, Git 커밋, 이미 수행된 외부 작업은 되돌리지 않습니다. 두 기능 모두 일반 워크플로 노드에만 적용되며 AUTO 모드 또는 AI-DYNAMIC 내부 노드는 지원하지 않습니다.

### 2. Feishu와 WeCom에서 워크플로 계속 또는 복구

Feishu 또는 WeCom의 1:1 채팅을 연결하면, 조건을 충족하는 워크플로가 일시 중지될 때 작업 카드가 전송됩니다. 데스크톱 앱에서 수동으로 중지한 경우도 포함됩니다.

1. **워크플로 계속**: 아직 완료되지 않은 현재 노드를 이어서 실행합니다.
2. **워크플로 복구**: 현재 노드는 성공했지만 워크플로가 다음 단계로 넘어가지 않은 경우, 노드를 다시 실행하지 않고 기존 결과를 사용해 계속 진행합니다.

알림은 기본적으로 켜져 있습니다. 「설정 → 일반 → IM 원격 개입 및 알림」에서 채널별로 「워크플로 계속 요청」을 끌 수 있습니다. 워크플로를 막 중지한 뒤 카드에 처리 중이라고 표시되면 잠시 기다린 다음 같은 카드에서 다시 시도하세요.

> [!NOTE]
> 원격 작업을 하려면 데스크톱 앱이 온라인 상태여야 합니다. 이번 업데이트에서는 IM을 통한 워크플로 시작, 중지, 다시 실행을 지원하지 않습니다. 업데이트 전에 이미 일시 중지된 워크플로의 카드를 한꺼번에 보내지 않습니다.

### 3. Agent 3종 추가 및 최초 설정 개선

- 「Agent 관리」에 DeepSeek Harness, ZCode, Qoder를 추가했습니다. ZCode는 커뮤니티 어댑터를 사용합니다. Windows ARM64에서는 기본 제공 Qoder 옵션을 사용할 수 없습니다. 기본 제공 CodeBuddy의 기본 표시 이름을 WorkBuddy로 바꿨으며 기존 설정은 유지됩니다.
- Agent를 추가하거나 편집할 때 「연결 요구 사항」에서 필요한 로컬 명령과 인증 방법을 확인할 수 있습니다.
- 최초 설정에서 Node.js, npm, npx를 계속 확인하지만, 검사에 실패해도 로컬 Agent를 감지할 수 있습니다. 감지 결과에서 미설치, 실행 환경 부족, 진단 실패를 구분합니다. 감지가 끝나거나 실패한 뒤에는 사용 가능한 Agent가 없어도 「나중에 설정」을 선택하면 메인 화면으로 들어가 나중에 설정을 완료할 수 있습니다.

### 4. Vista와 Meadow 테마 추가 및 밝은 모드와 어두운 모드별 배경화면 설정

「설정 → 개인 설정」에서 두 가지 새 테마로 바꿀 수 있습니다.

- **Vista**: 밝은 모드는 수채화 두루마리, 어두운 모드는 검은빛과 금빛의 눈 덮인 봉우리와 별이 빛나는 하늘을 담았습니다. 짙은 청록색과 살구빛 금색은 각 배경화면에서 가져왔습니다.
- **Meadow**: 밝은 모드는 순백보다 부드러운 새싹빛 녹색, 어두운 모드는 조용한 봄밤을 닮은 소나무 녹색을 사용합니다. 코드와 Diff 영역에는 더 밝은 배경을 사용해 읽기 쉽게 했습니다.

Gold Band, Vista, Meadow에는 기본 배경화면이 총 6장 포함됩니다. 밝은 모드와 어두운 모드에서 각각 「테마 배경화면」, 「사용자 지정」, 「사용 안 함」을 선택할 수 있습니다. 사용자 지정 배경화면은 「채우기」와 「맞추기」를 지원하며, 「최근 사용」 목록에서 삭제할 수 있습니다.

### 5. 대화 턴으로 이동하고 입력창 높이 조절

- 대화 왼쪽에 턴 탐색을 추가했습니다. 표시 위에 마우스를 올리면 메시지를 미리 볼 수 있고, 클릭하면 해당 턴으로 이동합니다. 아직 화면에 표시되지 않은 이전 턴으로도 이동할 수 있습니다.
- 홈과 대화 화면에서 입력창의 위쪽 가장자리를 드래그해 높이를 조절할 수 있습니다. 다른 대화로 바꿔도 높이가 유지되며, 아래로 끌어 낮게 줄이면 자동 높이 조절로 돌아갑니다.

### 6. Multica에서 로컬 역할과 워크플로 제거

연결한 뒤 Multica의 역할 관리에 있는 「Runtime」 탭에서 현재 실행 환경의 로컬 역할과 워크플로를 한곳에서 확인하고 기본 제공 항목이 아닌 항목을 제거할 수 있습니다. 제거할 때는 로컬 사본만 삭제되며 Multica의 공유 카탈로그에는 영향이 없습니다. 여러 리소스 작업을 연달아 요청하면 데스크톱 앱이 대기 중인 요청을 더 빠르게 처리합니다.

## 사용성 개선

### 1. 더 편리해진 사이드바와 대화

- 「최근 대화」에서 실행 기록을 펼치고, 대화 이름을 바꾸거나 고정할 수 있습니다. 사이드바 목록 아래쪽에 있는 버튼으로 항목을 더 불러옵니다. 실행 기록을 새로 고쳐도 현재 선택이 유지되며, 작업이 끝나면 진행 중 표시가 사라집니다.
- Markdown 표 본문에 테마의 기본 텍스트 색을 사용해 밝은 테마와 어두운 테마 모두에서 읽기 쉬워졌습니다.

### 2. 더 안정적인 앱 시작과 Agent 연결

- Agent 하나의 시작 설정이 잘못되어도 앱 전체의 시작을 막지 않습니다. WorkBuddy가 이후 턴에서 시작 방식을 바꾸면서 정상 로컬 연결을 끊는 문제를 수정했습니다.
- 일부 WebView 시작 오류를 수정했습니다. 지원하지 않는 환경에서는 해당 플랫폼에 맞는 업데이트 방법을 안내합니다. 새 버전의 MCP 클라이언트에서도 기본 제공 공유 메모리 도구를 더 안정적으로 찾을 수 있습니다.

### 3. 공식 웹사이트에 지식 베이스와 다운로드 메뉴 추가

공식 웹사이트와 Demo의 브랜드를 MALING으로 통일했습니다. 웹사이트에서 지식 베이스를 읽거나 다운로드 메뉴에서 플랫폼에 맞는 설치 프로그램을 선택할 수 있습니다.
