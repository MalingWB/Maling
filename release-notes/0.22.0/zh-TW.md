## 功能新增/調整

> [!IMPORTANT]
> 此版本會移轉本機設定。0.21.x 無法讀取升級後的設定；如需保留降版的選擇，請在升級前備份應用程式資料。

### 1. 在工作流圖中重試目前節點，或從失敗節點重跑

開啟會話的工作流執行圖，以滑鼠右鍵點選符合條件的節點：

1. **重試目前節點**：目前節點因異常而暫停、尚未往下執行時，可在原 Run 內重新執行該節點。先前的會話與產出會保留。
2. **從此節點重跑**：針對已執行完且失敗的紀錄（包括可重跑的歷史紀錄），使用任務最新儲存的工作流設定建立新 Run，從選定節點開始執行。原 Run 會保留為唯讀歷史紀錄。

> [!WARNING]
> 從失敗節點重跑會停止來源 Run 中仍在進行的執行作業，但不會復原工作區變更、Git 提交或已發生的外部操作。這兩種操作僅適用於一般工作流節點，不支援 AUTO 模式或 AI-DYNAMIC 內部節點。

### 2. 在飛書和企業微信上繼續或還原工作流

完成飛書（Feishu）或企業微信（WeCom）的私訊綁定後，符合條件的工作流暫停時（包括在桌面端手動停止），會傳送操作卡片：

1. **繼續工作流**：接著執行目前尚未完成的節點。
2. **還原工作流**：目前節點已成功、但尚未往下推進時，沿用既有結果繼續，不會再次執行該節點。

通知預設開啟。可在「設定 → 一般 → IM 遠端干預與通知」依管道關閉「工作流繼續請求」。如果剛停止後卡片顯示仍在處理中，稍後可點選同一張卡片重試。

> [!NOTE]
> 遠端操作需要桌面端保持連線。這次不支援透過 IM 啟動、停止或重跑工作流，也不會批次補發升級前已暫停的卡片。

### 3. 新增三種 Agent，首次引導更有彈性

- 「Agent 管理」新增 DeepSeek Harness、ZCode 和 Qoder。ZCode 使用社群轉接器；Windows ARM64 暫不提供內建 Qoder 選項。內建 CodeBuddy 的預設顯示名稱改為 WorkBuddy，既有設定會保留。
- 新增或編輯 Agent 時可查看「接入條件」，確認需要哪些本機指令和驗證方式。
- 首次引導仍會檢查 Node.js、npm 和 npx，但檢查未通過也能偵測本機 Agent。結果會區分未安裝、缺少執行環境和診斷未通過；偵測結束或失敗後，即使沒有可用的 Agent，也可點選「稍後設定」先進入主畫面，之後再完成設定。

### 4. 新增畫境和春野主題，淺色與深色可分別設定桌布

在「設定 → 個人化」可切換兩套新主題：

- **畫境（Vista）**：淺色是水彩長卷，深色是黑金色的雪峰與星空；黛青和金杏色分別取自兩張桌布。
- **春野（Meadow）**：淺色以比純白柔和的嫩芽綠為底，深色以松綠呈現靜謐的春夜；程式碼和 Diff 區域使用較亮的底色，維持清晰。

Gold Band、畫境和春野共提供 6 張內建桌布。淺色和深色可分別選擇「主題桌布」「自訂」或「停用」。自訂桌布支援「填滿」與「符合」，也可以從「最近使用」中刪除。

### 5. 會話可依回合跳轉，也能調整輸入框高度

- 會話左側新增回合導覽：滑鼠移到標記上可預覽訊息，點選即可跳到該回合，也能跳到尚未顯示的較早回合。
- 在首頁和會話頁，可拖曳輸入框上緣調整高度。切換會話時會保留高度；向下拖回較低的位置即可恢復自動調整。

### 6. Multica 支援解除安裝本機角色與工作流

連線後，可在 Multica 的「角色管理 → Runtime」同時查看目前執行環境中的本機角色和工作流，並解除安裝非內建項目。解除安裝只會移除本機副本，不會刪除 Multica 共用目錄中的內容。連續提交多項資源操作時，桌面端會更快處理排隊中的請求。

## 體驗優化

### 1. 側邊欄和會話更好用

- 可直接在「近期會話」展開執行紀錄、重新命名或置頂。側邊欄改為按下清單底部的按鈕載入更多項目；重新整理執行紀錄時會保留目前的選取位置，任務結束後也會即時停止旋轉提示。
- Markdown 表格內文使用主題的一般文字顏色，在深色和淺色主題下都更容易閱讀。

### 2. 啟動和 Agent 連線更穩定

- 單一 Agent 的啟動設定無效時，不再影響整個應用程式啟動。WorkBuddy 的後續對話也不會因切換啟動方式而中斷原本可用的本機連線。
- 修正部分 WebView 啟動失敗的問題，環境不受支援時會顯示對應平台的更新指引；改善新版 MCP 用戶端尋找內建共用記憶工具的相容性。

### 3. 官網新增知識庫和下載選單

官網和 Demo 統一使用 MALING 品牌。現在可以在官網閱讀知識庫，並從下載選單依平台選擇安裝程式。
