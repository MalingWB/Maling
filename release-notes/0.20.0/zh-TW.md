## 功能新增／調整

### 1. 支援飛書遠端介入與通知

離開電腦時，現在也可以透過飛書處理權限確認、Agent 追問和人工檢查，並接收任務結果通知。

使用流程如下：

1. 開啟「設定 → 一般 → IM 遠端介入與通知」，選擇飛書，確認權限後掃描 QR Code 連線。
2. 使用掃碼授權的帳號傳送一則私訊給機器人，完成綁定。
3. 收到卡片後，可以同意或拒絕權限、填寫單選、多選、文字及自訂答案，或處理人工檢查。

在桌面端、企業微信或飛書任一端處理後，結果會同步至其他已連線且啟用對應通知的管道；飛書卡片保留實際提交的答案，並停用已處理的控制項。

目前僅支援綁定帳號的一對一私訊，一個機器人連接一台裝置，不支援群組聊天或透過 IM 啟動、停止、重新執行任務。用戶端離線、電腦休眠或網路中斷時，無法保證即時收發。Lark 國際版尚未完成驗證。

> [!WARNING]
> **升級前請留意舊卡片與降級限制**
> 本次升級會清除舊版 IM 互動卡片的傳送記錄及相關訊息綁定，升級前收到的部分卡片可能失效，仍待處理的請求請回到桌面端處理。升級後的 IM 資料無法直接由舊用戶端讀取；如需保留降級能力，請在升級前備份應用程式資料。

### 2. 完善 Claude 原生子 Agent 與背景任務顯示

Claude 啟動子 Agent 時，可以在對話中的 Agent 列查看執行狀態，並在右側工作區開啟唯讀詳細資訊。同步執行和背景執行的子任務會顯示各自的訊息、權限請求與狀態，父回合結束不再將仍在執行的子任務誤判為中斷。

背景活動分開計時，減少將長時間閒置算入執行耗時的問題；背景回覆結束後，也可以正常複製和引用內容。

> [!NOTE]
> 需要 Claude ACP `0.90.0` 或更高版本，舊版本會提示升級。重新載入工作階段後繼續既有子 Agent，仍受介接器能力限制。Token 總計不包含背景喚醒的消耗，面板會顯示對應警示。

### 3. 完善遠端需求執行與結果交接

行內版的「需求管理」進一步完善開發任務、測試任務和遠端附件的處理：

1. 依開發、測試任務查看和執行需求；對應開發任務尚未完成時，測試任務會提示等待，但仍允許手動執行。
2. 點選「執行」後，需求內文、上游交付說明等脈絡會帶入對話；點選「傳送」才正式領取任務。
3. 傳送前可看到遠端附件的唯讀清單，傳送時下載並作為本次任務的輸入。單一附件下載失敗不會阻擋任務，缺少的資訊會告知 Agent。
4. Direct 模式等待明確的完成輸出後再回傳完成狀態，避免第一輪回覆結束就提前關閉需求；工作流程收尾會彙整整個工作項目的交付結果，供後續任務使用。

### 4. 支援遠端 Skill 多檔案雙向同步

支援在本機與 Multica 之間同步完整 Skill，包括 `SKILL.md` 和所需的指令碼、說明等支援檔案。在 Skill 全域管理頁點選「同步遠端 SKILL」，連線至 Multica 後選擇工作區和遠端 Skill，即可拉取至本機並查看同步結果；需要將本機 Skill 匯入遠端時，請在 Multica 端發起操作。

修復重新載入遠端清單時仍保留舊選取項目，以及同步異常後復原不完整的問題。

> [!CAUTION]
> **覆寫拉取會取代整個 Skill 目錄**
> 選擇覆寫本機 Skill 時，以遠端目錄內容為準；遠端不存在的本機檔案也會被刪除。請先儲存需要保留的本機修改。

### 5. 支援快速鍵開啟對話搜尋

按 `Ctrl+F`，或在 macOS 上按 `Cmd+F`，即可開啟對話搜尋並將焦點移至輸入框。再次按下會選取目前關鍵字，按 `Esc` 關閉後回到原來的控制項。

程式碼編輯器仍優先使用自己的檔案搜尋；其他對話方塊、選單或選擇器開啟時，不會疊加對話搜尋。

### 6. Git 推送前確認目標

原始碼管理推送前會顯示實際的「本機分支 → 遠端／目標分支」，方便確認程式碼將被推送至何處。首次發布分支時可以選擇遠端並設定上游；已有上游的分支會推送至實際追蹤的目標。

沒有上游的分支會標為「新分支」，減少將尚未發布的分支誤認為已同步的情況。

## 體驗最佳化

### 1. 更穩定的歷史閱讀和工作階段復原

修復向上翻閱時被自動跟隨拉回的問題，目前頁面不足一個畫面高度時也可以繼續載入更早的歷史。重新進入工作階段後，已處理的提問不會因為舊快取再次變成待處理。

繼續工作階段會沿用該工作階段實際儲存的模型與權限設定，減少舊工作流程設定導致無法繼續的問題。

### 2. 同名附件不再覆寫歷史內容

不同內容的同名附件會分別儲存，後續上傳不會覆寫歷史附件及其預覽。改善長檔名的儲存，路徑過深、無法安全儲存時給出明確提示。

### 3. 更好用的 Markdown 與檔案工作區

1. 修復對話中本機圖片的預覽，以及本機 HTML 連結的開啟問題，保留連結中的查詢參數和頁內定位。
2. Markdown 即時預覽使用面板的可用寬度，寬螢幕下減少不必要的兩側留白。
3. 內建佈景主題的預設編輯器字級調整為 `13px`，既有自訂字級保持不變。
4. 右側分頁出現顯示錯誤時，可以在該分頁重試，不再影響整個對話；同時改善多個檔案樹並存時的穩定性。

### 4. 修正 Token 重複累計

修復工作階段閒置後繼續對話時，Token 消耗被重複累計的問題；讀取既有記錄時也會修正可識別的重複累計。

### 5. 其他體驗最佳化

1. 修復 Windows 上查看檔案較多的提交或合併提交時，變更統計載入失敗的問題。
2. 改善中文語言自動比對，明確的簡體、繁體標記優先於地區判斷；既有手動語言設定保持不變。
3. 補齊常駐工作階段相關的多語言文案，修復部分工具提示未及時關閉的問題。
