## 功能新增/调整

### 1. 支持飞书远程干预与通知

离开电脑时，现在也可以通过飞书处理权限确认、Agent 追问和人工检查，并接收任务结果通知。

使用流程如下：

1. 打开「设置 → 通用 → IM 远程干预与通知」，选择飞书，确认权限后扫码接入。
2. 使用扫码授权的账号给机器人发一条私聊消息，完成绑定。
3. 收到卡片后，可以同意或拒绝权限、填写单选、多选、文本及自定义答案，或处理人工检查。

在桌面端、企业微信或飞书任一端处理后，结果会同步到其他已接入且启用对应通知的渠道；飞书卡片保留实际提交的答案，并禁用已处理的控件。

当前仅支持绑定账号的一对一私聊，一个机器人连接一台设备，不支持群聊或通过 IM 启动、停止、重跑任务。客户端离线、电脑休眠或断网时，无法保证实时收发。Lark 国际版尚未完成验证。

> [!WARNING]
> **升级前请留意旧卡片与降级限制**
> 本次升级会清理旧版 IM 交互卡片的投递记录及相关消息绑定，升级前收到的部分卡片可能失效，仍待处理的请求请回到桌面端处理。升级后的 IM 数据不能直接由旧客户端读取；如需保留降级能力，请在升级前备份应用数据。

### 2. 完善 Claude 原生子 Agent 与后台任务展示

Claude 发起子 Agent 时，可以在会话中的 Agent 行查看运行状态，并在右侧工作区打开只读详情。同步执行和后台执行的子任务会显示各自的消息、权限请求与状态，父回合结束不再把仍在运行的子任务误判为中断。

后台活动单独计时，减少将长时间空闲算入执行耗时的问题；后台回复结束后，也可以正常复制和引用内容。

> [!NOTE]
> 需要 Claude ACP `0.90.0` 或更高版本，旧版本会提示升级。重新加载会话后继续已有子 Agent，仍受适配器能力限制。Token 汇总不包含后台唤醒的消耗，面板会显示相应警示。

### 3. 完善远程需求执行与结果交接

行内版的「需求管理」进一步完善开发任务、测试任务和远程附件的处理：

1. 按开发、测试任务查看和执行需求；对应开发任务尚未完成时，测试任务会提示等待，但仍允许手动执行。
2. 点击「执行」后，需求正文、上游交付说明等上下文会带入会话；点击「发送」才正式领取任务。
3. 发送前可看到远程附件的只读清单，发送时下载并作为本次任务的输入。单个附件下载失败不会阻断任务，缺失信息会告知 Agent。
4. Direct 模式等待明确的完成输出后再回传完成状态，避免第一轮回复结束就提前关闭需求；工作流收尾会汇总整个工作项的交付结果，供后续任务使用。

### 4. 支持远程 Skill 多文件双向同步

支持在本地与 Multica 之间同步完整 Skill，包括 `SKILL.md` 和所需的脚本、说明等支撑文件。在 Skill 全局管理页点击「同步远程 SKILL」，连接 Multica 后选择工作空间和远程 Skill，即可拉取到本地并查看同步结果；需要把本地 Skill 导入远程时，在 Multica 侧发起操作。

修复重新加载远程列表时仍保留旧选择，以及同步异常后恢复不完整的问题。

> [!CAUTION]
> **覆盖拉取会替换整个 Skill 目录**
> 选择覆盖本地 Skill 时，以远程目录内容为准；远程不存在的本地文件也会被删除。请先保存需要保留的本地修改。

### 5. 支持快捷键打开会话搜索

按 `Ctrl+F`，或在 macOS 上按 `Cmd+F`，即可打开会话搜索并聚焦输入框。再次按下会选中当前关键词，按 `Esc` 关闭后回到原来的控件。

代码编辑器仍优先使用自己的文件查找；其他弹窗、菜单或选择器打开时，不会叠加会话搜索。

### 6. Git 推送前确认目标

源码管理推送前会展示实际的「本地分支 → 远程 / 目标分支」，方便确认代码将被推到哪里。首次发布分支时可以选择远程并设置上游；已有上游的分支会推送到实际跟踪的目标。

没有上游的分支会标为「新分支」，减少将尚未发布的分支误认为已同步的情况。

## 体验优化

### 1. 更稳定的历史阅读和会话恢复

修复向上翻阅时被自动跟随拉回的问题，当前页不足一屏时也可以继续加载更早历史。重新进入会话后，已处理的提问不会因为旧缓存再次变成待处理。

继续会话会沿用该会话实际保存的模型与权限设置，减少旧工作流配置导致继续失败的问题。

### 2. 同名附件不再覆盖历史内容

不同内容的同名附件会分别保存，后续上传不会覆盖历史附件及其预览。改善长文件名的保存，路径过深、无法安全存储时给出明确提示。

### 3. 更好用的 Markdown 与文件工作区

1. 修复会话中本地图片的预览，以及本地 HTML 链接的打开问题，保留链接中的查询参数和页内定位。
2. Markdown 实时预览使用面板的可用宽度，宽屏下减少不必要的两侧留白。
3. 内置主题的默认编辑器字号调整为 `13px`，已有自定义字号保持不变。
4. 右侧标签页出现渲染错误时，可以在该页重试，不再影响整个会话；同时改善多个文件树共存时的稳定性。

### 4. 修正 Token 重复累计

修复会话空闲后继续对话时，Token 消耗被重复累计的问题；读取已有记录时也会纠正可识别的重复累计。

### 5. 其他体验优化

1. 修复 Windows 上查看文件较多的提交或合并提交时，变更统计加载失败的问题。
2. 改善中文语言自动匹配，明确的简体、繁体标记优先于地区判断；已有手动语言设置保持不变。
3. 补齐常驻会话相关的多语言文案，修复部分悬浮提示关闭不及时的问题。
